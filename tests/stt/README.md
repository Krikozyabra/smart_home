# Синтетические модели STT

Файлы ONNX моделируют сигнатуру GigaAM-v3 CTC. Они используют настоящий тракт
sherpa-onnx с Fbank и CTC-декодированием. Классификация основана на уровне
синтетического сигнала и служит проверкой передачи данных и нормализации.
Качество распознавания речи проверяется отдельно.

Для регенерации файлов выполните `python3 tests/stt/generate_models.py`.
Достаточно стандартной библиотеки Python.
