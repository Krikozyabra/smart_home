Эти маленькие ONNX-графы проверяют вычисления через настоящий ONNX Runtime и
не распознают слова. Они не заменяют обученную модель «Нафаня».

`melspectrogram.onnx` размножает среднее входного PCM в 8 × 32 признака;
`embedding_model.onnx` размножает среднее окна 76 × 32 в 96 признаков;
`keyword.onnx` возвращает `sigmoid((mean(features) - 2) / 100)` для контекста
из 16 кадров. Благодаря этому тесты независимо вычисляют ожидаемую вероятность
с учётом перекрытия PCM, нормализации спектрограммы и истории обоих этапов.
Остальные графы проверяют границы контекста, неверные интерфейсы моделей и
некорректные численные результаты.

Бинарные файлы воспроизводимо создаются `python tests/oww/generate_models.py`.
Для сборки проекта Python, numpy, пакет onnx и сеть не нужны.
