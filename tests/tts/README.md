# Синтетические модели TTS

Граф `echo.onnx` возвращает токены, индексы дикторов и частоту в виде
масштабированных отсчётов, а также значения для проверки насыщения и округления
PCM16. Остальные графы проверяют интерфейс модели, прогрев и сбои при синтезе.

Для регенерации выполните `python3 tests/tts/generate_models.py` со стандартной
библиотекой Python. CTest загружает готовые файлы через ONNX Runtime. Для
запуска этих тестов достаточно локальных фикстур.
