# Функции проекта

Спецификации описывают ожидаемое поведение функций проекта.

Тесты находятся в папке [tests](../tests/).
Названия файлов с тестами конкретного модуля начинаются с имени соответствующего модуля с большой буквы.

| Функция | Спецификация | Модуль |
|---|---|---|
| Онтология | [Описание](ontology/) | `ontology` |
| Определение ключевого слова | [Описание](oww/) | `oww` |
| Обработка звука | [Описание](audio/) | `audio` |
| Основной цикл программы | [Описание](runtime/) | `runtime` |
