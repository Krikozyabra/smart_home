# Модуль синтеза речи (TTS)

ID: TTS

## Цель

Обеспечить локальный офлайн-синтез русской речи из текста в аудиоданные (PCM)
с использованием нейросетевой модели Silero TTS через ONNX Runtime на Raspberry Pi 4b.

## Требования

- TTS-001: Система настраивается структурой параметров: путь к файлу ONNX-модели,
  целевая частота дискретизации (8000, 24000 или 48000 Гц, по умолчанию 24000 Гц),
  имя диктора (по умолчанию "xenia"), число потоков CPU (по умолчанию 2, диапазон 1..4),
  путь к внешнему словарю символов (опционально). Корректность параметров и существование
  файла модели проверяются валидатором до инициализации инференса.
- TTS-002: Модуль принимает входную текстовую строку в кодировке UTF-8. Допускается
  явная разметка ударений знаком `+` перед ударной гласной. Пустая строка или строка,
  состоящая только из пробельных символов, возвращает пустой результат нулевой
  длительности без запуска инференса и без ошибок. То же правило действует,
  если токенизатор отфильтровал все символы. Некорректная UTF-8 вызывает
  `std::invalid_argument`.
- TTS-003: Синтез выполняется локально на CPU через ONNX Runtime с использованием
  совместимого ONNX-экспорта Silero TTS. Экспорт `v4_ru` принимает ручную
  разметку ударений.
- TTS-004: Результат синтеза возвращает аудиобуфер, предоставляющий нормализованные
  отсчёты `float` в диапазоне `[-1.0, 1.0]`, отсчёты в формате signed PCM16 (порядок
  байтов хоста), частоту дискретизации и длительность фрагмента в секундах.
- TTS-005: Модель загружается и прогревается при создании экземпляра синтезатора;
  рабочие ресурсы переиспользуются между вызовами. Модуль не создаёт фоновых потоков
  и не выполняет файлового ввода-вывода в процессе синтеза.
- TTS-006: Отсутствующие или повреждённые файлы модели, неподдерживаемая частота,
  неизвестный диктор, число потоков вне диапазона 1..4 или ошибки инференса вызывают
  исключения `std::invalid_argument` или `std::runtime_error`. NaN и бесконечность
  в результате инференса вызывают `std::runtime_error`. Конечные значения
  ограничиваются диапазоном `[-1, 1]` перед формированием обоих буферов.

## Границы

- Модуль выполняет только синтез аудиоданных в оперативной памяти (RAM).
  Воспроизведение через звуковую карту/ALSA, выбор устройства и микширование
  не входят в область ответственности модуля.
- Захват звука, VAD, распознавание речи (STT), семантический парсинг (NLU) и логика
  диалога принадлежат другим компонентам системы.
- Вычисления выполняются на CPU; специализированные ускорители (GPU/NPU) не требуются.

## Критерии приёмки

- Валидация отклоняет несуществующую модель, некорректные частоты и дикторов с `invalid_argument`.
- Корректная модель Silero TTS успешно инициализирует синтезатор и проходит прогрев.
- Непустая фраза на русском языке синтезируется в непустой аудиобуфер с корректной
  частотой дискретизации и положительной длительностью.
- Пустая строка возвращает пустой аудиобуфер без ошибок.
- Повторные вызовы синтеза не приводят к утечкам памяти и деградации производительности.
- Автоматические тесты проверяют валидацию и синтез на компактной тестовой ONNX-модели
  без зависимости от внешней сети.
