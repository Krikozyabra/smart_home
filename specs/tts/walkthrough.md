# Сборка и проверка TTS

`SMART_HOME_BUILD_TTS=ON` добавляет статическую библиотеку `SmartHome::Tts`.
Модуль загружает ONNX, проверяет интерфейс графа и прогревает выбранный голос
при создании. `synthesize()` возвращает моно PCM в двух форматах и длительность.
Подготовка `silero_ru.onnx` и пример API приведены в [README](../../README.md#офлайн-синтез-речи-tts).

## Команды проверки

Для теста обученной модели сначала подготовьте Python-окружение для экспорта
или укажите путь к готовому совместимому ONNX-файлу.

```sh
cmake -B build -S . -DSMART_HOME_BUILD_TTS=ON \
  -DSMART_HOME_TTS_EXPORT_PYTHON=/path/to/export-env/bin/python \
  -DSMART_HOME_TTS_TEST_MODEL="$PWD/build/tts/models/silero_ru.onnx"
cmake --build build --target tts_models
cmake --build build -j 4
ctest --test-dir build --output-on-failure
cmake --build build --target docs
git diff --check
```

## Результаты на Linux x86_64

- `tts_models` проверил SHA-256 официального `v4_ru.pt`, создал один ONNX-файл
  и сравнил отсчёты с исходной моделью для двух голосов на всех трёх частотах.
  Повторный запуск использовал проверенный файл. Проверка с локальным URL и
  неверной контрольной суммой завершилась ошибкой и сохранила прежний файл.
- `tts_tests` проверил токены, параметры, число отсчётов, насыщение PCM16,
  ошибки графа и восстановление работы после отказа инференса. Тест также
  выполнил 2000 последовательных синтезов после удаления загруженной модели
  и словаря. Проверки AddressSanitizer, LeakSanitizer и UndefinedBehaviorSanitizer прошли.
- `tts_model_tests` синтезировал фразы шестью голосами с частотами 8000, 24000
  и 48000 Гц. На рабочей машине с двумя потоками RTF составил 0,010–0,017,
  пиковый RSS процесса составил около 92 МиБ. RTF равен времени синтеза,
  делённому на длительность аудио. Время загрузки и прогрева измеряется отдельно.
- CTest прошёл все 38 зарегистрированных тестов. Сборка документации Doxygen
  и проверка пробельных ошибок Git прошли.

Измерения на Raspberry Pi 4b и оценка звучания требуют отдельной проверки.
