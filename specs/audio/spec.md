# Модуль для работы со звуком

ID: Audio

## Цель
Ползволить пользователю подключать микрофон и использовать его в 2 режимах: разовая запись на некотором отрезке времени и постоянная запись в кольцевой буфер заданного размера и размер кадра.

## Требования
- AM-001: В момент создания можно настроить: какой микрофон использовать, размер кольцевого буфера (через указание количества помещаемых кадров), размер кадра в миллисекундах для записи в кольцевой буфер, частота дискретизации, тип МОНО или СТЕРЕО. 
- AM-002: Есть функции для начала и остановки непрерывной записи в отдельном потоке, а считывать буфер можно читать из любого потока.
- AM-003: Есть функция для одноразовой записи какого-то промежутка времени в миллисекундах.

## Границы
- Функция из AM-002 записывает только в одном потоке
- Буфер из AM-001 можно считывать из любого потока
- Функция из AM-003 возвращает pcm вектор

## Критерии приемки
- Попытка подключения несуществующего микроофна выдается ошибка
- Функция из AM-002 запускается в отдельном потоке
- Только поток после запуска AM-002 имеет право записывать в кольцевой буфер аудио
- Любой поток может прочитать кольцевой буфер
- Можно прочитать настройки кольцевого буфера
- Функция из AM-003 корректно записывает указанное количество миллисекунд и возвращает pcm вектор
