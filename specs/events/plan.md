# План реализации модуля events

Основание — [spec.md](spec.md), [design.md](design.md), `AGENTS.md`.
Целевая платформа — Linux, Raspberry Pi 4b 8/120 (SD-card), CMake 3.20+, C++17.

## 1. Соответствие требованиям спецификации

| Требование | Описание | Реализация | Способ проверки |
|---|---|---|---|
| **EV-001** | Типобезопасная шина `EventBus` | `EventBus` с `std::type_index`, RAII `Subscription` | Тесты изоляции типов, времени жизни подписки, явной отмены |
| **EV-002** | Синхронная публикация и реентерабельность | `EventBus::publish` с копированием списка под мьютексом | Тест вызова `publish`/`subscribe` из обработчика события |
| **EV-003** | Реактор I/O дескрипторов | `Reactor::addHandler`, опрос через `poll(2)` | Тест готовности пайпа к чтению/записи и детекции обрыва связи |
| **EV-004** | Монотонные таймеры | `Reactor::addTimer`, `TimerHandle`, `steady_clock` | Тест разового и циклического таймера, отмена до срока |
| **EV-005** | Межпоточная очередь `post()` | Очередь с мьютексом, пробуждение через `eventfd` | Тест отправки событий из пула потоков в поток реактора |
| **EV-006** | Управление циклом реактора | `run()`, `step(timeout)`, `stop()` | Тест прерывания `run()` по `stop()`, пошаговый `step()` |
| **EV-007** | Безопасность исключений | Локализация сбоев обработчиков | Тест выброса исключения из подписчика без поломки шины |
